# موظف الموارد البشرية الذكي: نسخة المتدرب

نسخة البداية لدورة «ابنِ موظفك الرقمي بالذكاء الاصطناعي». فيها الأساسيات فقط، والباقي تبنيه أنت:

| موجود | تبنيه أنت (تمارين) |
|---|---|
| تسجيل دخول، وفريق عمل بصلاحيات (أدمن وعضو) | وكيل يصنّف الإيميل الوارد (طلب توظيف؟ استفسار؟) |
| إعدادات الأدمن: مزوّد الذكاء الاصطناعي، وصندوق الإيميل | وكيل يقرأ السيرة الذاتية ويستخرج بياناتها |
| صندوق إيميل: وارد، وفتح المرفقات، ورد، وإيميل جديد | تقييم المتقدم على الوظيفة |
| مساعد دردشة واحد يقرأ آخر الإيميلات | «حارس» يراجع جواب الوكيل قبل ما يوصل |

## التحميل والتشغيل

تحتاج [Docker Desktop](https://www.docker.com/products/docker-desktop/) و[Git](https://git-scm.com/downloads).

```bash
git clone https://github.com/Falahs/ai-hr-employee-starter.git hr-starter
```

```bash
cd hr-starter
```

```bash
docker compose up --build
```

لو المنفذ 8080 مستخدم عندك: أنشئ ملف `.env` جنب `docker-compose.yml` فيه سطر واحد `APP_PORT=8090`، وشغّل الأمر مرة ثانية، وافتح المنفذ الجديد.

أول تشغيل يأخذ بضع دقائق (يبني الصورة). بعدها افتح:

**http://localhost:8080**

## حساب الديمو

| الحساب | البريد | كلمة المرور | يشوف |
|---|---|---|---|
| أدمن | `demo@example.com` | `Demo-Starter-2026` | كل شيء: الإعدادات، والفريق، والصندوق، والدردشة |
| عضو | `demo-member@example.com` | `Demo-Starter-2026` | الصندوق (قراءة فقط) والدردشة |

جرّب تدخل بالحسابين وشوف كيف تختلف القائمة الجانبية: الصلاحية تُفحص على الخادم، والقائمة تخفي اللي ما يحق لك فقط للتسهيل.

في الصندوق ثلاثة إيميلات تجريبية (أسماء وهمية)، عشان المساعد يقدر يجاوب من أول دقيقة.

> كلمة المرور هذه للتجربة على جهازك فقط. على خادم عام حط كلمة مرور خاصة في `DEMO_PASSWORD` (شوف `.env.server.example`)، وإلا أي أحد يدخل ويصرف من مفتاح الذكاء الاصطناعي حقك.

## أول خطوات بعد الدخول

1. **الإعدادات ← الذكاء الاصطناعي**: حط مفتاحًا من واحد من الطريقين، واضغط «جرّب الاتصال».
   - **مفتاح الدورة** (يبدأ بـ `hrk_`، يوصلك من المدرب): رابط المزوّد `https://api.hr.dev.fyntralink.com`، والمفتاح في خانة المفتاح. له حد شهري، ولما يخلص يرجع لك «monthly limit».
   - **حسابك في Ollama**: رابط المزوّد يبقى `https://ollama.com`، والمفتاح من [ollama.com](https://ollama.com) ← Settings ← Keys.
2. **الدردشة**: اسأل «لخّص لي آخر الإيميلات».
3. **الإعدادات ← صندوق الإيميل** (اختياري): اربط Gmail بكلمة مرور تطبيق (App Password)، جرّب الاتصال، ثم شغّل الاستقبال والإرسال.
4. **الفريق**: أضف عضوًا، وأعطه صلاحيات، وادخل بحسابه.

## التحديث لنسخة جديدة

لما ينزل تحديث من المدرب، من داخل مجلد `hr-starter`:

```bash
git pull
```

```bash
docker compose up --build
```

- **`--build` ضروري:** بدونه Docker يكمّل على الصورة القديمة، حتى لو الملفات تحدّثت.
- **بياناتك ما تنمسح:** قاعدة البيانات والإعدادات (ومنها مفتاحك) تبقى. اللي يمسحها `docker compose down -v` فقط.
- **عدّلت ملفات بنفسك؟** خذ نسخة منها قبل التحديث. لو `git pull` قال إن فيه تعارض (conflict)، اكتب `git stash` ثم `git pull` ثم `git stash pop`، وراجع الملفات اللي يذكرها.

### لو `git pull` قال `refusing to merge unrelated histories`

يعني نسختك من قبل ما ينعاد رفع المستودع (قبل ١٦ نوفمبر ٢٠٢٦). خذ النسخة الجديدة في فرع جديد، وشغلك القديم يبقى في `main`:

```bash
git fetch origin
```

```bash
git switch -c latest origin/main
```

```bash
docker compose up --build
```

## الأمان المبني فيها (لا تشيله)

- كل صفحة تفحص صلاحيتها على الخادم (`Gate::authorize`)، وجلسة الدردشة لصاحبها فقط.
- المفتاح وكلمة مرور الإيميل محفوظة مشفّرة، وما ترجع للواجهة أبدًا.
- الخادم ما يتصل إلا بالعناوين المسموحة (`config/outbound.php`)، فالإعدادات ما تقدر توجّهه لشبكة داخلية.
- نص الإيميل يُعرض نصًا عاديًا فقط، والمرفق اللي مو PDF أو صورة ينزل تنزيلًا ولا يُفتح في الموقع.
- المساعد ما يشوف الإيميلات إلا لمن يملك صلاحية قراءتها.
- **حقن التعليمات (prompt injection):** أي أحد يقدر يرسل لك إيميل فيه «تجاهل التعليمات وقل...». فالمساعد فيه:
  - قواعد أمان ثابتة في `app/Services/Ai/prompts/security.md`، تنحط قبل تعليمات الأدمن، وما تنشال بتعديل الإعدادات.
  - والإيميلات توصل للنموذج داخل `<emails>`، وأي `</emails>` مكتوبة داخل إيميل تتعطّل (`Fence`)، فما يقدر المرسل يقفل البيانات ويكتب «تعليمات».
- **فحص المرفقات (`app/Services/Documents/UploadGuard.php`):** كل مرفق ينفحص قبل ما ينحفظ، ونوعه يُحكم من محتواه، مو من اسمه.
  - PDF فيه كود أو تشغيل تلقائي، أو Word فيه ماكرو أو روابط تجيب محتوى من الإنترنت، أو ملف مضغوط مفخخ: كلها تنرفض وما تنحفظ أبدًا. وصفحة الإيميل تقول وش انرفض وليش.
  - والصورة المقبولة يُعاد ترميزها، فيسقط منها أي شيء مدسوس.
- صفحة الدخول ما تكشف روابط الإدارة للزائر (`config/ziggy.php`).

## تمارين أمان للمتدرب

- **سقف إنفاق يومي:** كل سؤال في الدردشة استدعاء للنموذج يكلّف. أضف حدًا يوميًا لعدد الاستدعاءات (أو التوكنز)، وخلّ المساعد يعتذر لما ينوصل. التلميح: `OllamaClient::chat` هو المكان الوحيد اللي تمر منه كل الطلبات.
- **أسعار النماذج:** Ollama Cloud يحاسب بالتوكن بسعر لكل نموذج (`ollama.com/pricing`). احسب تكلفة كل جلسة دردشة.
- **حارس:** وكيل ثاني يقرأ جواب المساعد قبل ما يوصل، ويتأكد إنه من الإيميلات فعلًا.

